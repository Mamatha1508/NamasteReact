#  Food Delivery App (React)
A modern food delivery web application built using React. This project demonstrates component-based architecture, API integration, and responsive UI design.

##  Live Demo
https://mamatha-fooddeliveryapp.netlify.app/

##  GitHub Repository
 https://github.com/Mamatha1508/NamasteReact.git

---

##  Features
- Browse list of restaurants and food items  
- Dynamic data rendering using APIs  
- Search and filter functionality  
- Add items to cart  
- Responsive UI for different screen sizes  
- Component-based architecture  

---

##  Tech Stack

- React.js  
- JavaScript (ES6+)  
- HTML5  
- Tailwind CSS 
- React Router
- Redux
- Jest

---

##  Project Structure
--src
  |--- components / Reusable UI components
  |----components / __tests__ folder for  testing
  |--- utils / helper functions
  |-- Redux / state management

##  Installation & Setup

1. Clone the repository  : git clone https://github.com/Mamatha1508/NamasteReact.git
2. cd NamasteReact
3. npm install
4. npm start
